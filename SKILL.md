# Kotlin Style Guide Skills

> The official Android Kotlin style guide — packaged for AI coding agents.

This skill pack includes the official Kotlin style guide from the Android
documentation: https://developer.android.com/kotlin/style-guide

## Included Style Guides

### Mobile
- **Kotlin** - Naming, formatting, braces, whitespace, KDoc documentation

## Installation Options

### Install Everything (This Skill)
```bash
npx skills add achanu/kotlin-styleguide-skills
```

### Install Individual Languages
```bash
npx skills add achanu/kotlin-styleguide-skills/kotlin
```

## How It Works

When you install this skill:
1. The style guide is copied to your agent's skills directory
2. Your AI coding agent reads it when generating Kotlin code
3. Generated code follows the official style conventions automatically
